# Project Checklists

Use this folder to keep project ideas, refactors, and multi-prompt work from getting lost.

## How To Use

- Start each new idea from `TEMPLATE.md`.
- Keep each checklist focused on one outcome.
- Update status as work moves: `Proposed`, `Active`, `Blocked`, `Done`.
- Prefer small checkboxes that can be completed in one coding pass.
- Add notes when a decision is made so the next prompt has context.

## Naming

Use short kebab-case filenames:

- `webgl-rendering-architecture.md`
- `member-dashboard-preview-polish.md`
- `assessment-form-ui-pass.md`
