# Unreal Learning Pipeline

Status: Active
Created: 2026-06-22

## Goal

Build a repeatable system for learning Unreal from YouTube videos without losing the thread between prompts.

## Tasks

- [ ] Add first YouTube video link to `learning/unreal/source-log.md`.
- [ ] Capture available captions or rough notes.
- [ ] Summarize the video into `learning/unreal/video-notes/`.
- [ ] Pull out exact Unreal build steps into `learning/unreal/build-notes/`.
- [ ] Create a checklist for any repeatable workflow.
- [ ] Mark unclear terms or systems for follow-up.
- [ ] Test one learned technique in a small Unreal project.

## Notes

- Keep notes short and practical.
- Prefer timestamps and build steps over full transcripts.
- If a video teaches a large system, split it into multiple smaller build notes.
